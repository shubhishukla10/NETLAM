# NETLAM 

This repository contains all the files related to the submission titled "NETLAM: An Automated LLM Framework to Generate and Evaluate Stealthy Hardware Trojans", along with tools and scripts for creation of DAGs from netlists, identifying vulnerable points in the design, inserting and analyzing hardware Trojans and functional equivalence check. Below is a description of the files and their roles in the project.

## Overview

This project demonstrates the automated LLM framework flow, along with methodologies to introduce and detect stealthy hardware Trojans, which are not included in Trust-Hub. The repository includes:
- Gate-level netlists of AES-128 and its submodules. The Verilog codes are sourced from Trust-Hub.
- Python API scripts for Creating DAGs from the netlists, identifying vulnerable points, inserting stealthy Trojans in the vulnerable points, and checking for functional equivalences.
- Documentation and examples for all the three functionalities of the framework.

## Repository Structure

### **Gate-Level Netlists**
This folder contains the gate-level netlists of the AES-T1000, AES-T1200 Trojan-Free and Trojan-Infected versions. The netlists are generated using Yosys:
- **`mapped_netlist_clock_gate_T1200.v`**
  Mapped gate-level netlist of Clock-gate Trojan-infected AES-T1200.
- **`mapped_netlist_data_tampering_T1200.v`** 
  Mapped gate-level netlist of Data Tampering Trojan-infected AES-T1200. 
- **`mapped_netlist_free_T1000.v`**  
  Mapped gate-level netlist of Trojan-Free AES-T1000.
- **`mapped_netlist_free_T1200.v`**
  Mapped gate-level netlist of Trojan-Free AES-T1200.
- **`mapped_netlist_gate_level_T1200.v`**
  Mapped gate-level netlist of Gate-Level Trojan-infected AES-T1200.
- **`mapped_netlist_in_T1000.v`**
  Mapped gate-level netlist of Trojan-infected AES-T1000.
- **`mapped_netlist_in_T1200.v`**
  Mapped gate-level netlist of Trojan-infected AES-T1200.
- **`mapped_netlist_intermittent_T1200.v`**
  Mapped gate-level netlist of Intermittent Signal Tampering Trojan-infected AES-T1200.
- **`mapped_netlist_logic_level_T1200.v`**
  Mapped gate-level netlist of Logic-Level Trojan-infected AES-1200.

---

### **Instructions**
This folder contains the pre-defined instructions to the three LLMs.
- **`dag_inst.txt`**  
  Pre-defined instruction for the LLM to create DAGs and detect vulnerable points in the design.
- **`equivalence.txt`**
  Pre-defined instruction for the LLM to check for functional equivalence between the golden reference and Trojan-infected netlists.
- **`Trojan_insert.txt`**
  Pre-defined instruction for the LLM to modify and insert stealthy Trojan in specified module.

---

### **LLM Outputs**
This folder contains all the outputs provided by the three LLMs along with the Trojan inserted Verilog codes.
- **Trojan Inserted Verilog Codes**
  This folder contains all the Trojan inserted Verilog codes generated by the LLM.
	- **`trojan_inserted_clock_gating.v`**
	  Clock-gating Trojan-infected `aes_128` module. 
	- **`trojan_inserted_data_tampering.v`**
	  Data tampering Trojan-infected `xS` module.
	- **`trojan_inserted_gate_level.v`**
	  Gate-level Trojan-infected `S` module.
	- **`trojan_inserted_intermittent.v`**
	  Intermittent signal tampering Trojan-infected `aes_128` module.
	- **`trojan_inserted_logic_level.v`**
	  Logic-level trojan-infected `table_lookup` module.
- **`final_analysis_dag_with_CVSS_AES-T1000.txt`**  
  Generated analysis report with DAG and vulnerable points for AES-T1000.
- **`final_analysis_dag_with_CVSS_AES-T1200.txt`**
  Generated analysis report with DAG and vulnerable points for AES-T1200.
- **`functional_equivalence_result_clock_gate.txt`**
  Generated equivalence report for clock-gating Trojan in AES-T1200.
- **`functional_equivalence_result_data.v`**
  Generated equivalence report for data tampering Trojan in AES-T1200.
- **`functional_equivalence_result_final_AES-T1000.txt`**
  Generated equivalence report for AES-T1000.
- **`functional_equivalence_result_final_AES-T1200.txt`**
  Generated equivalence report for AES-T1200.
- **`functional_equivalence_result_gate_level.txt`**
  Generated equivalence report for gate-level Trojan in AES-T1200.
- **`functional_equivalence_result_intermittent.txt`**
  Generated equivalence report for intermittent signal tampering Trojan in AES-T1200.
- **`functional_equivalence_result_logic_level.txt`**
  Generated equivalence report for logic-level Trojan in AES-T1200.
